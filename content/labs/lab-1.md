## 1. АНАЛІЗ ТА МОДЕЛЮВАННЯ СИСТЕМИ

**Актуальність теми:** У сучасному веб-програмуванні існує гостра потреба у зручних та швидкодіючих інструментах для керування контентом та даними користувачів. ## 2. РОЗРОБЛЕННЯ АДАПТИВНОГО WEB-ЗАСТОСУНКУ

Файлова структура проєкту організована логічно: HTML-документ (`index.html`), стилі (`css/style.css`) та скрипти (`js/script.js`) зберігаються окремо.

Для побудови адаптивної сітки інформаційних карток було використано **CSS Grid**, що забезпечило зручне багаторядкове відображення контенту. Навігація реалізована з використанням медіа-запитів (`@media`), завдяки чому на мобільних пристроях стандартне меню трансформується у компактне «бургер-меню».

**Фрагмент реалізації медіа-запитів (`style.css`):**
```css
/* Адаптація під планшети та мобільні пристрої */
@media (max-width: 768px) {
    .cards-container {
        grid-template-columns: repeat(2, 1fr);
    }
    nav { 
        display: none; 
    }
    .burger-menu { 
        display: block; 
    }
}

```

## 3. ВСТАНОВЛЕННЯ ТА НАЛАШТУВАННЯ СЕРЕДОВИЩА NODE.JS. EXPRESS.JS

Середовище розробки Node.js було успішно встановлено, проєкт ініціалізовано командою `npm init -y`. Для спрощення роботи з маршрутизацією встановлено фреймворк Express.js.

Створено файл `server.js`, у якому реалізовано REST API з підтримкою HTTP-методів (GET, POST, PUT, DELETE).

**Фрагмент реалізації сервера (`server.js`):**

```javascript
const express = require("express");
const app = express();
app.use(express.json());

let students = [];

// GET /students - отримання списку
app.get("/students", (req, res) => {
    res.json(students);
});

// POST /students - додавання нового студента
app.post("/students", (req, res) => {
    const { id, name, group } = req.body;
    students.push({ id, name, group });
    res.status(201).json({ message: "Студента додано" });
});

app.listen(3000, () => {
    console.log("Server started on port 3000");
});

```
