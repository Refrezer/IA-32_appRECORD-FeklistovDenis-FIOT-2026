**Актуальність теми:** У сучасному веб-програмуванні існує гостра потреба у зручних та швидкодіючих інструментах для керування контентом та даними користувачів. ## 2. РОЗРОБЛЕННЯ HTTP-СЕРВЕРА (NODE.JS + EXPRESS.JS)

HTTP-сервер обробляє запити від клієнтів та повертає відповіді. Для реалізації використано платформу Node.js, яка забезпечує високу продуктивність та асинхронність, а також фреймворк Express.js для спрощення створення маршрутів.

**Код сервера (`server.js`):**

```javascript
const express = require("express");
const app = express();

app.use(express.json());

let students = [];

// GET: Отримання списку
app.get("/students", (req, res) => {
    res.json(students);
});

// POST: Додавання запису
app.post("/students", (req, res) => {
    const { id, name, group } = req.body;
    const newStudent = { id, name, group };
    students.push(newStudent);
    res.status(201).json({ message: "Студента додано", student: newStudent });
});

app.listen(3000, () => {
    console.log("Server started on port 3000");
});
